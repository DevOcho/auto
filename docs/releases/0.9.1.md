# auto 0.9.1

**Coming from 0.8? Read the
[0.9.0 release notes](https://devocho.github.io/auto/releases/0.9.0/) first:**
every existing cluster has to be recreated once, which resets its local
databases. This release changes nothing else about 0.9.0.

## What changed

- **The Linux download starts on Ubuntu 24.04 again.** 0.9.0's needed glibc
  2.42, so it failed at once on anything older than Ubuntu 25.10 with
  ``version `GLIBC_2.42' not found``. It is now always built on Ubuntu 24.04
  (glibc 2.39), and every release checks that it starts on Ubuntu 24.04 and
  Debian 13 before it is published. Linux needs Ubuntu 24.04 or newer,
  Debian 13 or newer, or a current Fedora or Arch.

## Upgrading

From 0.8, follow the
[0.9.0 upgrade steps](https://devocho.github.io/auto/releases/0.9.0/#upgrading):
`auto update` installs 0.9.1.

If you installed 0.9.0 on Linux and it won't start, run the installer again.
It keeps your `~/.auto/config/local.yaml`:

```bash
curl -fsSL https://www.devocho.com/auto.sh | bash
```
